Tuần 7 Ngôn Ngữ Thiết Kế Phenikaa University

What Is Verilog?

Verilog Là Gì Và Vì Sao Kỹ Sư Thiết Kế Số Cần Nó?

Đã đến lúc chúng ta dịch các sơ đồ khối (Block Diagrams) và máy trạng thái (FSM) thành mã code. Nhưng hãy nhớ: Verilog KHÔNG PHẢI là C hay Python. Tuần này, chúng ta sẽ đập bỏ "Tư duy Lập trình phần mềm" để làm quen với "Tư duy Mô tả phần cứng" (Hardware Description).

Phân biệt được rõ ràng HDL (Verilog/VHDL) với ngôn ngữ phần mềm.

Hiểu cấu trúc của một module cơ bản: input, output, wire, reg.

Nắm vững khái niệm thực thi "Song song" (Parallelism) trong thiết kế số.

Biết cách dùng lệnh assign để mô tả các cổng logic tổ hợp.

Chuẩn Bị Trước Buổi Học

Sai lầm phổ biến nhất của sinh viên mới là cố gắng "ép" Verilog chạy như một phần mềm với hàng tá lệnh for-loop. Trong Verilog, mọi dòng lệnh assign đều tạo ra một sợi dây điện và một cổng logic vật lý, và chúng chạy đồng thời cùng một lúc.

Checklist Tự Học

Tư Duy Khởi Động

  • Khi bạn viết c = a + b trong C++, CPU phải tính toán qua vài chu kỳ xung nhịp. Còn trong Verilog, câu lệnh đó tạo ra bộ linh kiện gì?
  • Tại sao người ta gọi Verilog là mô tả "song song" (parallel) thay vì "tuần tự" (sequential)?
  • "Module" trong Verilog giống với khái niệm nào bạn từng thấy khi học về Mạch tổ hợp (Tuần 4)?

Khái Niệm Cốt Lõi & Demo Trực Quan

1 Ngôn ngữ mô tả phần cứng (HDL)

Verilog (hay VHDL) không sinh ra các tệp .exe để chạy trên hệ điều hành. Nó là "bản vẽ kỹ thuật" dùng text. Phần mềm biên dịch (Synthesizer) sẽ đọc Verilog và "nối dây" các Transistor/Cổng logic lại với nhau bên trong chip (FPGA/ASIC).

2 Tính song song (Parallelism)

Trong phần cứng vật lý, dòng điện chạy qua mọi cổng logic cùng một lúc. Do đó, các khối assign hay các module trong Verilog hoạt động song song và độc lập, không quan tâm dòng nào viết trước, dòng nào viết sau.

Demo: Verilog To Hardware Visualizer (Mạch Half Adder)

Bài toán: Mô tả mạch cộng Bán tổng (Half Adder). Hãy thử click trực tiếp vào khối Input A và Input B trong bản vẽ SVG. Bạn sẽ thấy 2 dòng lệnh assign bên code Verilog sẽ thực thi đồng thời, tương ứng với dòng dữ liệu chạy qua phần cứng vật lý.

half_adder.v 
module half_adder (
    input  wire a,
    input  wire b,
    output wire sum,
    output wire cout
);

    // Tính tổng (Sum) dùng cổng XOR
    assign sum  = a ^ b;

    // Tính cờ nhớ (Carry Out) dùng cổng AND
    assign cout = a & b;

endmodule
Hai lệnh assign chạy hoàn toàn độc lập và song song với nhau.

Từ Vựng Tiếng Anh Chuyên Ngành

HDL

Ngôn ngữ mô tả phần cứng

(Hardware Description Language) Ngôn ngữ dùng để thiết kế kiến trúc chip thay vì phần mềm.

Module

Khối thiết kế

Khối xây dựng cơ bản trong Verilog, đại diện cho một mạch điện cụ thể (như Black box).

Wire / Reg

Dây dẫn / Thanh ghi

Các kiểu dữ liệu chính. Wire để nối mạch tổ hợp, Reg thường dùng lưu giá trị trong mạch tuần tự.

Assign

Lệnh gán liên tục

Dùng để tạo ra các mạch logic tổ hợp (Combinational Logic). Các lệnh assign chạy song song.

Lời Khuyên Từ Mentor

Sửa Lỗi Tư Duy (Misconception)

Nhiều sinh viên học Verilog sau C/C++ nên mang thói quen "lập trình tuần tự". Nhớ rằng: Viết Verilog KHÔNG PHẢI là viết thuật toán để CPU chạy từng dòng. Viết Verilog là bạn đang "mô tả cấu trúc dây điện và linh kiện" để nhà máy đúc ra.

"Think Hardware Before Coding."

Quy tắc số 1: Trước khi gõ bất kỳ dòng code Verilog nào, hãy tự hỏi: "Mạch điện mình đang muốn tạo ra (MUX, Adder, hay Flip-Flop) trông như thế nào?" Hãy vẽ nó ra giấy trước!

Kết Nối Dự Án (Mini-Projects)

Mọi dự án phức tạp đều bắt đầu từ việc khai báo các Module đơn giản. Dưới đây là các Module nền tảng bạn nên thử tự viết code Verilog:

Basic Logic Gates

Viết module cho cổng AND, OR, XOR

2-to-1 MUX

Sử dụng toán tử điều kiện (?:)

Half/Full Adder

Dùng lệnh assign để tính Sum và Cout

D Flip-Flop

Tập làm quen với khối always @(posedge clk)

Hành Động Sau Buổi Học

Task Tuần Này (Module Declaration)

Mỗi bạn hãy chọn 1 mạch cơ bản (VD: MUX 2-1 hoặc Half Adder), xác định danh sách cổng, và thử viết một cấu trúc module rỗng đăng lên Group lớp:

module [ten_mach] (
    input wire [ten_input1],
    input wire [ten_input2],
    output wire [ten_output]
);
    // Bạn chưa cần viết logic ở đây!
endmodule
Mục tiêu sinh viên đạt được
  • Hiểu Verilog là ngôn ngữ mô tả kiến trúc phần cứng (HDL).
  • Phân biệt rõ sự khác biệt với ngôn ngữ phần mềm (C/C++).
  • Giải thích được cấu trúc của một module và các ports (input/output).
  • Hiểu tính thực thi song song (Parallelism) của lệnh assign.
  • Kết nối được kiến thức mạch tổ hợp với mã nguồn Verilog.
